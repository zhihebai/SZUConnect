# 平台差异

正式交付平台为 macOS 与 Windows。

| 功能 | macOS | Windows |
| --- | --- | --- |
| 界面 | SwiftUI 桌面窗口 | Win32／Direct2D |
| 后台守护 | 菜单栏常驻 | 通知区域托盘 |
| 凭据 | 系统钥匙串 | 系统凭据管理器 |
| 登录时启动 | 用户选择后注册 | 用户选择后注册 |
| Wi-Fi 找网与电源控制 | 用户选定的已记住开放网络，独立电源开关 | 受 Windows WLAN／位置权限与硬件限制 |
| 首次使用引导 | 操作引导与设置清单 | 操作引导与设置清单 |
| HTTP 传输 | 固定认证物理通道与 URLSession 网址检测 | 固定认证物理通道使用 libcurl／Schannel，普通网址仍用 WinHTTP |
| 网站检测详情 | 保存本次结果与策略 | 保存本次结果与策略 |
| 联网显示 | 系统与校园直连分别检测，校园核验独立显示 | 相同；换网后重新检测系统路径 |
| 辅助功能 | SwiftUI 辅助标签 | UI Automation 提供者 |

Windows 可移植核心用于跨平台规则检查，mock SDK 用于有限语法检查；它们不能替代原生 MSVC 构建或实际界面与设备验收。

Windows 提供一键构建、原生核心测试、隔离窗口自检和 ZIP 打包脚本。`--observe-only` 仍可进行真实检测，但不写正式数据或提交校园认证；`--offline-smoke` 使用假服务并自动退出，两种模式不可同时启用。参数及回执说明见 [Windows 构建](../BUILD-WINDOWS.md)。

macOS 与 Windows 的网络权限、后台执行、系统代理和接口信息不同，读不到可靠信息时使用未知状态，不推定网络身份。

两端均支持物理出口匹配、并存网卡选择、TUN 与网站请求隔离、优先恢复、只读补查及关联 DNS 有限重传。普通网站故障不触发自动校园认证，也不修改 VPN、代理、DNS 或路由。Windows 11 的校园网、无线电及权限行为需进行[实体测试](../WINDOWS-TESTING.md)。

## iOS 代码复用与编译探索

iOS 工程用于 Swift/C++ 代码复用探索，尚不属于正式交付平台。实机体验、后台行为及发行需单独适配与验证。[iOS 构建](../BUILD-MAC.md#ios-代码复用与编译探索)
