# 平台差异

目前发布 macOS 与 Windows 版。

| 功能 | macOS | Windows |
| --- | --- | --- |
| 界面 | SwiftUI 桌面窗口 | Win32／Direct2D |
| 后台运行 | 菜单栏 | 系统托盘 |
| 凭据 | 系统钥匙串 | 系统凭据管理器 |
| 登录时启动 | 用户选择后注册 | 用户选择后注册 |
| Wi-Fi 找网与电源控制 | 自动连接已记住且无需 Wi-Fi 密码的校园网络；自动打开 Wi-Fi 单独设置 | 相同；另受 Windows WLAN／位置权限与硬件限制 |
| 首次使用引导 | 操作引导与设置清单 | 操作引导与设置清单 |
| HTTP 传输 | 固定认证物理通道与 URLSession 网址检测 | 固定认证物理通道使用 libcurl／Schannel，普通网址仍用 WinHTTP |
| 网站检测详情 | 显示本次结果及所用设置 | 显示本次结果及所用设置 |
| 联网显示 | 系统与校园直连分别检测，校园核验独立显示 | 相同；换网后重新检测系统路径 |
| 辅助功能 | SwiftUI 辅助标签 | UI Automation 提供者 |

Windows 可移植核心用于跨平台规则检查，mock SDK 用于语法检查；原生构建、界面和设备行为在 Windows 上单独验证。

Windows 的构建脚本包含核心测试、隔离窗口自检和 ZIP 打包，另提供两种测试模式：

- `--observe-only`：检测真实网络，不写正式数据或提交校园认证。
- `--offline-smoke`：使用假服务，检查后自动退出。

两种模式不能同时启用。参数及回执见[Windows 构建](../BUILD-WINDOWS.md)。

macOS 与 Windows 的网络权限、后台运行、系统代理和网卡信息不同。无法读取的信息显示为“未知”，不据此判断校园网络身份。

两端按选定的校园网卡绑定认证请求，分别处理 TUN 和常用网址请求，并支持换网优先恢复、网址补查及有限次数的 DNS 重试。普通网站故障只更新诊断，应用不因此提交校园认证，也不修改 VPN、代理、DNS 或路由。Windows 11 的校园网、Wi-Fi 开关及权限见[实机测试](../WINDOWS-TESTING.md)。
