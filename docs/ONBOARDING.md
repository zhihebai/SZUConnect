# 首次设置

1. **连接校园网**：先在系统中选择校园 Wi-Fi，或插上网线。
2. **保存账号**：核对教学／办公区或宿舍区，保存校园账号，检测并按需登录。
3. **记住网络**：在连接页的网络确认区选择“核验并记住校园网络”。应用先核验校园服务，通过后才保存；Wi-Fi 和网线分别记住。进度及结果显示在操作旁。
4. **选择自动恢复**：开启“自动重连”；需要找回无线连接时，选择已记住的校园 Wi-Fi 并开启“自动找网”。

“允许自动打开 Wi-Fi”是独立选项，默认关闭。只保存账号不会自动启用找网；连接其他 Wi-Fi 或网线时，应用不会抢网。

“仅本次信任”与记住网络分别选择。本次信任在退出、换网或休眠后失效，不保存网络，也不证明校园身份。

已联网的非校园网络无需校园登录。校园服务无法确认时，不会新增网络记忆或发送账号密码；开启自动重连后，仍须满足账号、网络权限、校园核验及保护条件。

## 设置卡住时

- 不能记住网络：查看网络确认区原位显示的结果；基础联网正常不等于校园服务核验通过。
- 看不到 Wi-Fi：检查系统定位权限和无线服务。
- 未自动重连：查看首页清单中的账号、网络记忆和自动恢复选项。
- 已在线但某网站打不开：先排查网站或代理，避免反复校园登录。

引导可跳过，也可从帮助或设置重新查看，不会重置已有设置。更多问题见[使用手册](USER-GUIDE.md)。
