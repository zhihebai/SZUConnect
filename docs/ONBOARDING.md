# 首次设置

1. **连接校园网**：先在系统里连上校园 Wi-Fi，或者接好校园网线。
2. **保存账号**：填校园账号，核对登录区域，点“保存账号”。
3. **检测连接**：需要认证时再登录；已经能上网就不用重复登录。
4. **记住网络**：在“自动重连”卡片里选“核验并记住校园网络”。校园服务核验通过后才会保存，Wi-Fi 和网线分别记住。
5. **开启自动重连**：应用会定期检测，持续掉线且校园服务核验通过时，尝试登录。

需要自动找网时，在设置里选中已记住的校园 Wi-Fi，再开启“自动找网”。电脑未连接网络时，应用会搜索并连接所选 Wi-Fi；也可单独允许应用打开 Wi-Fi 开关。已有其他 Wi-Fi、热点或网线连接时，应用不会切换网络。

“仅本次信任”不保存网络，换网、休眠或退出后就会失效。应用核验的是校园登录服务，每次恢复连接前都会重新检查。

## 遇到问题

- **不能记住网络**：查看按钮旁的校园服务核验结果，即使当前能上网，也需通过这项核验才能记住网络。
- **看不到 Wi-Fi**：检查系统位置与隐私权限、Wi-Fi 开关和找网目标。
- **没有自动重连**：看看连接页的设置清单和暂停提示。
- **只有个别网站打不开**：先检查网站或代理，不用反复登录校园网。

引导随时可以跳过；之后在“设置”里打开“使用教程”就能再看一遍，已有的设置会保留。详细说明见[使用教程](USER-GUIDE.md)。
