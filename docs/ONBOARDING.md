# 首次设置

1. **连接校园网**：先在系统中连接校园 Wi-Fi，或接入校园网线。
2. **保存账号**：填写校园账号，核对登录区域，点击“保存账号”。
3. **检测连接**：需要认证时再登录；已经能上网时无需重复登录。
4. **记住网络**：在“自动重连”卡片中选择“核验并记住校园网络”。校园服务核验通过后才会保存，Wi-Fi 和网线分别记住。
5. **开启自动重连**：应用会定期检测，在持续掉线且校园服务核验通过时尝试登录。

需要自动连接校园 Wi-Fi 时，在设置中选定已记住的网络并开启“自动找网”。是否允许自动打开 Wi-Fi，可另行选择。连接其他 Wi-Fi、热点或网线时，应用不会另行找网。

“仅本次信任”不保存网络，换网、休眠或退出后失效；登录前仍需核验校园服务。核验用于确认校园登录服务，不代表对网络整体安全作出保证。

## 遇到问题

- **不能记住网络**：查看按钮旁的核验结果。能够上网与校园服务核验通过是两回事。
- **看不到 Wi-Fi**：检查系统位置与隐私权限、Wi-Fi 开关和找网目标。
- **没有自动重连**：查看连接页的设置清单及暂停提示。
- **只有个别网站打不开**：先检查网站或代理，不必反复校园登录。

引导可随时跳过，之后可在“设置”中打开“使用教程”，已有设置会保留。详细说明见[使用教程](USER-GUIDE.md)。
