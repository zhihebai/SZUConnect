# 使用与排查

## 开始使用

1. [安装应用](INSTALLATION.md)，通过系统连接校园 Wi-Fi 或网线。
2. 保存校园账号，核对登录区域，点击检测并按需登录。
3. 需要自动恢复时，记住当前网络并开启“自动重连”。Wi-Fi 与网线分别记住。

首页清单会提示缺少的设置。引导可跳过，之后仍可重新查看。

## 检测与自动恢复

“快速检测”检查基础联网；“完整检测”还会检查已启用的网址。系统联网、校园直连和校园服务核验分别显示；已能上网时，无需为完成设置重复登录。网站报错或证书异常不会触发校园重登。

自动恢复要求账号、网络记忆和校园服务核验均满足条件。连续检测异常后才会尝试登录；密码错误或结果不明时会暂停。90 秒保护限制重复登录，不影响检测。

“自动找网”只恢复你选定的已记住开放校园 Wi-Fi，默认关闭；自动打开 Wi-Fi 电源另行选择。已连接其他 Wi-Fi、热点或网线时不会抢网，也不读取系统无线密码。

## 常见问题

- **登录失败**：核对账号、区域和暂停原因。结果不明时先检测，避免反复提交。
- **没有自动恢复**：查看首页清单，确认账号、网络记忆及对应开关已设置。
- **找不到 Wi-Fi**：先通过系统连接该网络，再检查定位权限、无线服务和硬件开关。
- **已联网但网站打不开**：查看该网站结果，检查网站和代理。校园登录不能解决所有网站问题。
- **关闭后仍在运行**：应用会留在菜单栏或托盘，从其菜单选择“退出”。

## 记录与隐私

记录展示近期检测和认证结果，通过比例不是网速，也不代表持续在线率。诊断会去除账号、密码等敏感内容，分享前仍请检查。

账号保存在系统安全存储中，设置和网络记忆保存在本机。应用不修改 VPN、代理、DNS 或路由。[数据位置与删除方式](PRIVACY.md)
