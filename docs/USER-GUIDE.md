# 使用教程

深大随连适用于深圳大学粤海、丽湖校区，可以检测联网、登录校园网，并按设置自动重连。首次使用可跟随应用内引导，之后可在“设置”中重新打开“使用教程”。

## 安装应用

- Windows：下载并运行 EXE，或解压 ZIP 后运行 `SZUConnect.exe`。
- macOS：打开 DMG，把“深大随连”拖进“应用程序”。

系统要求和首次打开的提示，见[安装说明](INSTALLATION.md)。

## 连接与账号

1. 先在系统里连上校园 Wi-Fi，或者接好校园网线。
2. 在“连接 → 校园账号”填校园网登录页上的账号和密码，点“保存账号”。
3. “登录区域”可以用“自动选择”，也可以按位置选“教学／办公区”或“宿舍区”。
4. 点“检测连接”。需要认证时，再按提示点“登录校园网”。

账号保存在本机的 Windows 凭据管理器或 macOS 钥匙串里，保存后不会立即登录。已经能上网时，无需重复认证。

在“设置 → 关于 → 账号存储与隐私”可删除已保存账号。删除的是本机保存的账号和密码，不会注销校园网账号或断开当前网络。

## 选择检测方式

| 方式 | 用途 |
| --- | --- |
| 快速检测 | 检查基础联网；Apple 或 Microsoft 有一项通过就结束 |
| 完整检测 | 检查两项基础联网，以及已启用的常用网址 |

常用网址按需添加，建议启用不超过 3 个。检测只检查网站是否回应，不测试页面中的登录、聊天等功能。

## 自动重连

| 模式 | 行为 |
| --- | --- |
| 手动检测 | 点击按钮后检测或登录 |
| 定时检测 | 定期检查联网，不会自动登录 |
| 自动重连 | 定期检查联网；持续掉线、且校园服务核验通过时，尝试登录 |

确认当前连的是校园网后，选“核验并记住校园网络”。应用会先检查校园服务，通过后才保存网络记忆。Wi-Fi 和网线要分别记住。

在“设置 → 记住的校园网络”中，可修改备注或忘记网络。备注只用于应用内显示；不同网络同名时，会用编号、连接方式和区域区分。

“仅本次信任”不保存网络，换网、休眠或退出应用后失效。已记住的网络在重连前也会重新核验校园服务。

密码错误、证书异常或登录结果未确认时，自动重连会暂停，按页面提示处理。登录后 90 秒内通常不会重复提交，期间仍可检测连接。

## 自动找网

在“设置 → 校园 Wi-Fi 找网”里选中已记住的校园 Wi-Fi，再开启“断连时，自动找回记住的校园 Wi-Fi”。电脑未连接 Wi-Fi 或网线时，应用会搜索并连接所选 Wi-Fi。此功能配合“自动重连”使用，只连接无需 Wi-Fi 密码的校园网络。

Wi-Fi 密码和校园网账号密码不同：前者用于连上无线网络，后者用于连上后的校园登录。只用网线无需寻找 Wi-Fi，可跳过找网设置。

需要自动打开 Wi-Fi 时，再开启“找网时允许打开 Wi-Fi”。两个开关默认关闭；已有 Wi-Fi、手机热点或网线连接时，应用不会切换网络。

读取 Wi-Fi 名称可能需要系统的位置与隐私权限，按页面提示处理即可。应用不会读取系统保存的 Wi-Fi 密码。

## 网络排查

“网络详情”展示联网结果和排查工具。使用代理、VPN 或 TUN 时，可对照以下三项：

- **当前上网方式**：电脑按系统网络设置访问外网的结果。
- **校园直连**：应用通过校园 Wi-Fi 或网线直接检测的结果。
- **校园登录服务核验**：是否已确认适用的校园网登录服务。

排查时先看当前能否上网，再看校园直连和校园服务核验。只有个别网站报错时，查看对应网站结果即可，无需反复登录校园网。

“刷新”只更新连接信息；“联网检测对比”旁的“检测连接”重新检查联网，无需返回页面顶部。

| 情况 | 建议 |
| --- | --- |
| 登录失败 | 核对账号、登录区域和页面提示；结果未确认时先检测连接 |
| 没有自动重连 | 查看连接页的设置清单，检查账号、网络记忆和暂停提示 |
| 找不到校园 Wi-Fi | 先在系统里连一次，再检查名称读取权限、找网目标和 Wi-Fi 开关 |
| 只有个别网站打不开 | 查看该网站的检测结果，并在浏览器中确认；必要时检查网站或代理设置 |

## 记录与帮助

“记录”页按时间展示检测和登录结果，点击结果可查看详情。通过比例表示检测通过的次数占比，不是网速或持续在线时长。

“设置 → 帮助”提供常见问题和学校上网服务入口。分享截图或排查报告前，请隐藏个人信息。[隐私说明](PRIVACY.md)

## 启动、退出与升级

需要随系统启动时，可以在设置里开启 Windows 的“开机启动”或 macOS 的“登录时打开”。自动重连仍按所选模式运行。

关掉窗口后，应用会留在 Windows 托盘或 macOS 菜单栏里。要完全关闭，从图标菜单选“退出”；退出后不再自动重连。

macOS 默认在关闭最后一个窗口后收起 Dock 图标，最小化或隐藏窗口时保留。需要一直显示，可在设置里开启“始终显示 Dock 图标”。

升级时，Windows 下载并运行新 EXE；macOS 先退出旧版，再用新应用替换“应用程序”里的旧版。账号、设置和网络记忆都会保留。[升级说明](INSTALLATION.md#升级)
