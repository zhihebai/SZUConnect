# 使用教程

深大随连可以检测联网、登录校园网，并按设置自动重连，适用于深圳大学粤海、丽湖校区。首次使用可跟随应用内引导，之后也可在“设置”中打开“使用教程”。

## 安装应用

- Windows：下载并运行 EXE。
- macOS：打开 DMG，把“深大随连”拖进“应用程序”，再从那里打开。

系统要求和首次打开的提示，见[安装说明](INSTALLATION.md)。

## 连接与账号

1. 先在系统里连上校园 Wi-Fi，或接好校园网线。
2. 在“连接 → 校园账号”填校园网登录页上的账号和密码，点“保存账号”。
3. “登录区域”推荐“自动选择”。它表示认证入口，不代表所在楼宇；需要手选时，以学校说明或实际登录页为准。
4. 点“检测连接”。需要认证时，再按提示点“登录校园网”。

使用 `net.szu.edu.cn` 网页登录时，可选“教学／办公区”。若提示入口冲突或无法确定，按页面提示处理；登录结果不明时，先做完整检测，不要反复提交。

账号保存在本机的 Windows 凭据管理器或 macOS 钥匙串里。可在“设置 → 关于 → 账号存储与隐私”删除；这不会注销校园网账号或断开当前网络。

<details>
<summary>账号区为什么收起来了？</summary>

账号已保存且没有未保存的修改时，填写区会收起，只显示脱敏概况。点“校园账号”可展开；收起不会清空输入或显示明文密码。尚未保存或正在修改时，填写区保持可见。

“常用网址”也可收起。引导跳转到这些区域时会先展开，已有设置不变。

</details>

## 选择检测方式

| 方式 | 用途 |
| --- | --- |
| 快速检测 | 检查基础联网；Apple 或 Microsoft 有一项通过就结束 |
| 完整检测 | 检查两项基础联网，以及已启用的常用网址 |

页面顶部和“网络详情 → 联网检测对比”都可切换检测方式，两处同步。切换后再点“检测连接”；切换本身不会检测，也不改写已有结果及时间。

在“常用网址”中添加想检查的网址，也可快捷添加百度、腾讯网。快捷添加默认不勾选，也不会访问网站；之后勾选才参与完整检测。最多保存 12 个，建议启用不超过 3 个。

检测只检查网站是否回应，不测试页面中的登录、聊天等功能。

<details>
<summary>修改网址会影响正在进行的检测吗？</summary>

仅修改未勾选的网址时，正在进行的检测、已有结果和原定检测时间保持不变。更改已勾选目标、顺序或网址连接方式后，旧轮次会失效，后续按新设置检测。保存失败时保留原检测配置。

</details>

## 自动重连

| 模式 | 行为 |
| --- | --- |
| 手动检测 | 点击按钮后检测或登录 |
| 定时检测 | 定期检查联网，不会自动登录 |
| 自动重连 | 定期检查联网；持续掉线且校园服务核验通过时，尝试登录 |

确认当前连的是校园网后，点“核验并记住校园网络”，通过核验后再开启“自动重连”。Wi-Fi 和网线要分别记住；网线保持插着但校园登录失效时，也由自动重连处理。

已记住的网络在重连前仍会核验校园服务。自动重连模式下，基础联网正常时也会自动核验；想立即确认，可点“核验校园服务”，这一步不会登录。

密码错误、证书异常或登录结果未确认时，自动重连会暂停。按页面提示处理，避免反复提交；登录后 90 秒内通常不会重复登录，期间仍可检测连接。

### 管理记住的网络

在“设置 → 记住的校园网络”中，可修改备注或忘记网络。备注只影响显示；忘记网络会撤销它的自动恢复资格，账号和系统保存的 Wi-Fi 仍会保留。

“忘记全部网络”会先确认，取消、关闭或按 Escape 不会执行。“仅本次信任”不保存网络，换网、休眠或退出后失效。

<details>
<summary>同名 Wi-Fi、认证入口和自动核验</summary>

校园不同区域的 Wi-Fi 可能同名。连接特征不同的网络需要分别核验并记住；不必仅因切换接入点重复记住。可靠确认当前连接对应唯一记录时，设置页才显示“当前连接”。名称本身不提供登录资格。

网络记录中的“认证入口”表示保存的登录方式，不代表电脑所在位置。核验或记住网络后，操作区会显示本次结果；未保存时，按提示处理后再试。

自动重连模式下，核验成功后随监测约每 15 分钟刷新，失败按原节奏重试，无需为完成确认重复登录。

忘记全部网络后，Windows 同时关闭自动找网；macOS 保留找网开关，但需重新记住并选中校园 Wi-Fi 才能找网。

</details>

## 自动找网

在“设置 → 校园 Wi-Fi 找网”里选中已记住的校园 Wi-Fi，再开启“断连时，自动找回记住的校园 Wi-Fi”。电脑未连接 Wi-Fi 或网线时，应用会找回所选 Wi-Fi，再按“自动重连”设置处理校园登录。

需要自动打开 Wi-Fi 时，再开启“找网时允许打开 Wi-Fi”。两个开关默认关闭；已有 Wi-Fi、手机热点或网线连接时，应用不会切换网络。

- macOS：目前只找回无需无线密码的校园 Wi-Fi。
- Windows：还可使用该 Wi-Fi 已保存的系统连接；需要无线密码时，请先在系统中连接并保存。应用不读取无线密码。

Wi-Fi 密码用于连接无线网络，校园网账号密码用于之后的校园登录，两者不同。只用网线可跳过找网设置。

读取 Wi-Fi 名称可能需要系统的位置与隐私权限；有线认证不需要这项权限。

## 网络排查

先在浏览器打开常用网页，再按遇到的情况查看：

| 情况 | 建议 |
| --- | --- |
| 登录失败 | 核对账号、登录区域和页面提示；结果未确认时先检测连接 |
| 没有自动重连 | 查看连接页的设置清单、网络记忆和暂停提示 |
| 找不到校园 Wi-Fi | 先在系统里连一次，再检查名称读取权限、找网目标和 Wi-Fi 开关 |
| 只有个别网站打不开 | 在浏览器中确认，必要时检查该网站或代理设置，无需反复登录校园网 |
| 多台设备轮流掉线 | 检查校园账号的在线设备额度，暂停其他设备的自动重连，再观察 |
| 开启代理或 TUN 后校园网异常 | 打开“网络详情 → 校园直连设置”，按所用软件查看[操作步骤](PROXY-DIRECT.md) |

“网络详情”可展开或收起。“刷新”只更新连接信息；“联网检测对比”旁的“检测连接”可重新检测，无需回到页面顶部。

<details>
<summary>怎样看懂网络详情？</summary>

- **当前上网方式**：电脑按系统网络设置访问外网的结果。
- **校园直连**：应用通过校园 Wi-Fi 或网线直接检测的结果。
- **校园登录服务核验**：是否已确认适用的校园网登录服务。

先看能否上网，再比较两列与校园服务核验。两列结果不同，不代表一定需要重新登录。点“联网检测对比”标题旁的 ⓘ 可查看检测范围和连接方式。

检测发现校园登录页时，应用会进一步检查是否需要认证，再按自动重连设置处理。

“常用网址”中的连接方式只影响自选网址，不改变基础检测、校园核验或 TUN。

校园直连设置可离线阅读，检测可随时停止。需要处理配置文件时，再展开高级选项，选择、预览并确认；保存前会加密备份，之后须在代理软件重新应用。

</details>

## 记录与反馈

“记录”页按时间展示检测和登录结果，点结果可看详情。通过比例按基础联网可用的检测次数计算，不含常用网址，也不代表网速或持续在线时长。

遇到故障，可在“记录 → 排查与反馈”复制摘要或保存 JSON 报告，附上当时的操作和问题，提交 [Issue](https://github.com/zhihebai/SZUConnect/issues) 或[来信](mailto:hizhihebai@163.com)。标题可写“【深大随连】邮件主题”；“关于”页可复制邮箱和查看邮件示例。

摘要和报告不会自动上传或发送。分享截图前，请隐藏个人信息。[隐私说明](PRIVACY.md)

<details>
<summary>报告范围和系统崩溃信息</summary>

搜索和“只看失败”只影响页面显示，不缩小导出范围。报告包含最近 24 小时、最多 360 次检测，以及最多 300 条操作记录。

新记录保留失败耗时、检测时的匿名环境，以及当轮核验和重连保护；恢复联网后仍可回看，旧记录缺少的明细不会补写。

macOS 在选定位置后固定报告内容，在后台整理和保存；可停止或关闭窗口取消，不扫描系统崩溃日志，报告标为“未收集”。Windows 可按需附系统留存的本程序崩溃元数据，读取情况会在报告中注明。

</details>

## 启动、退出与升级

需要随系统启动时，在设置里开启 Windows 的“开机启动”或 macOS 的“登录时打开”。自动重连仍按所选模式运行。

关窗后，应用留在 Windows 托盘或 macOS 菜单栏。要完全退出，从图标菜单选“退出”；退出后不再自动重连。

macOS 关掉最后一个窗口后默认隐藏 Dock 图标，最小化或隐藏窗口时保留。需要常驻时，开启“始终显示 Dock 图标”；固定或最近使用的入口由 macOS 管理。

升级无需先删除数据，账号、设置和网络记忆都会保留。[升级说明](INSTALLATION.md#升级)

## 卸载与开源许可

在“设置 → 关于 → 卸载应用”中操作，默认保留账号和本机数据；需要清理时再勾选。Windows 也可从系统“已安装的应用”卸载。macOS 须从“应用程序”中的应用执行；需要恢复外部代理配置时，请先撤销，再卸载。[卸载说明](INSTALLATION.md#卸载)

完整开源许可可在“设置 → 关于 → 开源许可”中离线阅读、复制。展开分组后选择项目或组件即可。
