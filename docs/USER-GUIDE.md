# 使用教程

深大随连适用于深圳大学粤海、丽湖校区，可检测联网、登录校园网，并按设置自动重连。首次使用可跟随应用内引导；之后可在“设置”中重新打开“使用教程”。

## 安装应用

- Windows：下载并运行 EXE，或解压 ZIP 后运行 `SZUConnect.exe`。
- macOS：打开 DMG，将“深大随连”拖入“应用程序”。

系统要求及首次打开说明见[安装说明](INSTALLATION.md)。

## 连接与账号

1. 先在系统中连接校园 Wi-Fi，或接入校园网线。
2. 在“连接 → 校园账号”填写校园网登录页使用的账号和密码，点击“保存账号”。
3. “登录区域”可用“自动选择”，也可按位置选择“教学／办公区”或“宿舍区”。
4. 点击“检测连接”。需要认证时，再按提示点击“登录校园网”。

账号保存在本机的 Windows 凭据管理器或 macOS 钥匙串中。保存账号不会立即登录。已经能够上网时，无需重复认证。

## 选择检测方式

| 方式 | 用途 |
| --- | --- |
| 快速检测 | 检查基础联网；Apple 或 Microsoft 任一项通过即可结束 |
| 完整检测 | 检查两项基础联网，以及已启用的常用网址 |

常用网址可按需添加，日常建议启用不超过 3 个。检测只检查网站是否回应，不测试页面中的登录、聊天等功能。

## 自动重连

| 模式 | 行为 |
| --- | --- |
| 手动检测 | 点击后才检测或登录 |
| 定时检测 | 定期检查联网，不自动登录 |
| 自动重连 | 定期检查联网，持续掉线且校园服务核验通过时尝试登录 |

确认当前连接的是校园网后，选择“核验并记住校园网络”。应用会检查校园服务，通过后才保存网络记忆。Wi-Fi 和网线需分别记住。

“仅本次信任”不保存网络，换网、休眠或退出应用后失效；登录前仍需检查校园服务。记住网络也不代表它今后无需核验。

密码错误、证书异常或登录结果未确认时，自动重连会暂停。请按页面提示处理；登录后 90 秒内通常不会重复提交，但仍可检测连接。

## 自动找网

在“设置 → 校园 Wi-Fi 找网”选择已记住的校园 Wi-Fi，再开启“断连时寻找已记住的校园 Wi-Fi”。此功能配合“自动重连”使用，只支持无需 Wi-Fi 密码的校园网络。

如需自动打开已关闭的 Wi-Fi，再开启“找网时允许打开 Wi-Fi”。这两个开关默认关闭。已接入其他 Wi-Fi、手机热点或网线时，应用不会另行找网。

读取 Wi-Fi 名称可能需要系统位置与隐私权限，请按页面提示处理。应用不读取系统保存的 Wi-Fi 密码。

## 网络排查

“网络详情”展示当前联网结果，并提供排查工具。使用代理、VPN 或 TUN 时，可对照以下三项：

- **当前上网方式**：电脑按系统网络设置访问外网的结果。
- **校园直连**：应用通过校园 Wi-Fi 或网线直接检测的结果。
- **校园登录服务核验**：是否已确认适用的校园网登录服务。

这三项可能不同。系统能上网，不代表校园直连正常；单个网站报错，也不代表校园网掉线。

| 情况 | 建议 |
| --- | --- |
| 登录失败 | 核对账号、登录区域和页面提示；结果未确认时先检测，不要反复登录 |
| 没有自动重连 | 查看连接页的设置清单，检查账号、网络记忆及暂停提示 |
| 找不到校园 Wi-Fi | 先在系统中连接一次，再检查名称读取权限、找网目标和 Wi-Fi 开关 |
| 只有个别网站打不开 | 查看该网站的结果，并在浏览器中确认；必要时检查网站或代理设置 |

## 记录与帮助

“记录”页可按时间查看检测与登录结果，点击色块查看详情。通过比例反映检测结果，不代表网速或持续在线时长。

“设置 → 帮助”提供常见问题和学校上网服务入口。分享截图或排查报告前，请检查并隐藏个人信息。[隐私说明](PRIVACY.md)

## 启动、退出与升级

需要随系统启动时，可在设置中开启 Windows 的“开机启动”或 macOS 的“登录时打开”。自动重连仍按所选模式运行。

关闭窗口后，应用会留在 Windows 托盘或 macOS 菜单栏中。需要完全关闭时，从图标菜单选择“退出”；退出后不再自动重连。

升级前先退出应用。Windows 下载并运行新 EXE；macOS 用新应用替换“应用程序”中的旧版。账号、设置和网络记忆会保留。[升级说明](INSTALLATION.md#升级)
