# 校园直连设置

开启代理或 TUN 后校园网连不上时，打开“连接 → 网络详情 → 校园直连设置”，按所用软件操作。步骤可离线阅读。

1. 选择代理软件，按下方说明添加校园直连规则。
2. 在代理软件中保存并应用，保留原有规则。
3. 回到深大随连，点“检测校园连接”。这一步只检测，不提交账号密码。

选择操作说明：[Clash Verge Rev](#clash-verge-rev) · [v2rayN](#v2rayn) · [Clash Party](#clash-party) · [其他软件](#其他代理客户端)

检测完成后，查看“校园登录页”“公共网址”的结果和处理建议。公共网址仅检查 Apple 的固定测试页；单项超时不代表整台电脑无法上网，可先用浏览器试开常用网页。校园页面有响应，也不代表已经核验校园身份或登录成功。

<details>
<summary>两列检测结果有什么区别？</summary>

“校园直连”不使用系统代理，不改变其他应用的连接方式；“当前上网方式”沿用系统设置。两列仍可能受 TUN 影响，浏览器、代理软件和本应用也可能采用不同路径。

检测标题旁的 ⓘ 有完整说明。只有校园直连查不到固定地址时才会尝试备用查询，系统设置列不使用这项机制。

</details>

## Clash Verge Rev

以下步骤按 v2.5.8 的“规则”模式说明，无需寻找配置文件：

1. 打开“订阅”，右键当前订阅，选择“编辑规则”。
2. 按下表添加规则，均选择“添加前置规则”；IP-CIDR 项勾选“跳过 DNS 解析”。
3. 保存后，回到深大随连点“检测校园连接”。

| 类型 | 内容 | 代理策略 |
| --- | --- | --- |
| DOMAIN | `net.szu.edu.cn` | DIRECT |
| IP-CIDR | `172.30.255.42/32` | DIRECT |

已有相同规则时，先检查原策略，避免重复添加。按此方式保存的自定义规则会随当前订阅保留，更新订阅不会丢失。[官方说明](https://www.clashverge.dev/guide/rules.html)

全局模式不按逐项规则分流。

### TUN 下仍无法连接

- **宿舍地址仍被接管**：在“设置 → 系统设置 → 虚拟网卡模式”旁点齿轮，可在“排除自定义网段”中追加 `172.30.255.42/32`，保留原有条目。此项在自动路由开启时可用。
- **校园域名无法解析**：直连规则和网址解析（DNS）是两项设置。DNS 覆写会影响订阅原有的解析设置，不应只为一个域名直接开启；需要定向合并时，使用下方高级流程。

客户端会将界面中的 TUN 设置写回配置，不能仅凭扩展脚本写入了排除项，就认定运行时已生效。保留严格路由等原有保护，调整后再检测。

## v2rayN

以下步骤按 v7.25.6 说明，macOS 与 Windows 均在当前规则集中追加两条校园规则：

1. 打开“设置 → 路由设置”，在“预定义规则集列表”中双击当前使用的规则集。
2. 在深大随连选择 v2rayN，点“复制 v2rayN 校园规则”，再回到 v2rayN 的“规则集设置”。
3. 点“从剪贴板中导入规则”。出现“是否追加规则”时选“是”，保留原有规则，不选全部替换。
4. 在规则列表中，分别选中新加的两条规则，各自右键“上移至顶”。不要多选后只操作一次。
5. 点“确定”保存，再关闭外层“路由设置”窗口，让客户端重新加载；完成后回到深大随连检测校园连接。

复制内容只包含校园路由规则，不含节点订阅或整套配置。使用自定义完整配置时，客户端的图形路由设置可能不参与生成；此流程也不修改 DNS 或 TUN 设置。[路由设置说明](https://github.com/2dust/v2rayN/wiki/Description-of-some-ui#路由设置)

其他版本的菜单可能不同。保存规则不代表校园连接已经恢复，完成后仍应回到应用检测。

## Clash Party

以下步骤按 v2.0.4 的标准模式说明，简易模式不显示此入口：

1. 打开“订阅管理”，在当前订阅卡片的“⋯”或右键菜单中选择“编辑规则”。
2. 添加 `DOMAIN`、`net.szu.edu.cn`、`DIRECT`；再添加 `IP-CIDR`、`172.30.255.42/32`、`DIRECT`，并勾选“跳过 DNS 解析”。两条均选择“添加前置规则”。
3. 保存后，回到深大随连检测校园连接。

使用自定义 Smart 覆写时，注意其规则是否覆盖了前置规则。[规则编辑实现](https://github.com/mihomo-party-org/clash-party/blob/v2.0.4/src/renderer/src/components/profiles/edit-rules-modal.tsx#L885)

## 其他代理客户端

支持自定义分流规则的客户端，可按以下方式设置，菜单名称以客户端说明为准：

1. 打开客户端的规则或路由设置。
2. 为精确域名 `net.szu.edu.cn` 和 IP 地址 `172.30.255.42` 添加直连规则；要求填写 CIDR 时，使用 `172.30.255.42/32`。
3. 将规则放在可能冲突的规则之前，保留其他规则及默认处理方式。保存并应用后，回到深大随连点“检测校园连接”。

已有相同目标时，先检查原来的处理方式。客户端不支持单独添加例外时，不要直接导入其他软件的配置或替换整套分流。

<details>
<summary>系统代理、TUN、规则模式有什么区别？</summary>

## 两组设置的区别

系统代理和 TUN 决定哪些连接交给代理软件：

- **系统代理**：支持系统代理的应用按这项设置联网。
- **TUN**：通过虚拟网卡接管更多连接，校园登录也可能受影响。

规则、全局和直连决定如何处理这些连接：

- **规则／自定义路由**：按客户端规则选择直连或代理，名称以所用客户端为准。
- **全局**：统一走选定的代理，也可以统一选直连。
- **直连**：不经过代理服务器，也可以在 TUN 开启时使用。

添加校园直连规则后，应启用客户端的“规则”或“自定义路由”；全局模式可能不采用这些规则。

两组设置可以同时生效，具体范围以客户端为准。深大随连不会代为切换模式。

</details>

<details>
<summary>地址解析和定期核验（技术说明）</summary>

## 网址解析兼容

TUN 有时会拦住电脑查找校园登录地址。两端先使用当前网卡的 DNS，失败后自动尝试阿里公共 DNS 的加密解析，无需另行设置。

这项兼容仅处理校园登录地址和 Apple、Microsoft 两个基础检测地址，不改变系统 DNS、代理或 TUN。取得地址后，应用仍通过原物理连接访问；校园登录前重新核验校园 HTTPS 服务。

地址仅保留在内存中。普通复用遵守 DNS 有效期，最长 5 分钟；两种解析均不可用时，HTTPS 可尝试此前 24 小时内取得的地址，仍须重新通过证书核验。HTTP 检测不使用过期地址。换连接后不借用旧地址，退出应用后清除。

网络记忆有效、基础检测正常时，应用随定时检测约每 15 分钟重新核验校园服务。失败后继续重试，不要求重新记住网络，也不因此清除暂停或冷却。备用解析不能修复代理软件的所有路由问题；校园直连规则仍需按实际客户端配置。

</details>

## Windows 移动热点与 TUN

同时使用移动热点和 TUN 时，Windows 网络共享可能使校园直连失败，表现为校园页面超时。仅添加域名直连规则未必有效。

只用本机时，可暂时关闭“设置 → 网络和 Internet → 移动热点”，再点“检测连接”。需要继续共享时，可使用系统代理，或按代理软件说明调整共享来源。关闭热点会让其他设备暂时断网。

应用检测当前校园物理连接的相关设置，在连接页和校园直连设置中提示，并提供系统设置入口；不会自动关闭热点、修改共享或删除网络记忆。提示和匿名排查报告均只记录固定状态。

相关机制见 [Windows TUN 出口兼容性说明](https://github.com/XTLS/Xray-core/pull/7092)。

## 高级：脚本与独立配置

仅在熟悉配置文件、且普通操作不能满足需要时使用。

<details>
<summary>展开文件处理步骤与限制</summary>

手动规则、扩展脚本和文件处理集中在助手的高级选项中。普通选择页只展示客户端步骤，Mihomo YAML 与 sing-box JSON 位于“已有完整配置文件”中。Clash Verge Rev 用户可优先使用上方图形界面，不必寻找 `Script.js`。

| 类型 | 适用文件 |
| --- | --- |
| Clash Verge Rev 扩展脚本 | 原来为空、客户端默认，或由深大随连生成的脚本；已有自定义脚本不覆盖 |
| Mihomo YAML | 已有、由本人维护的独立完整配置 |
| sing-box JSON | 已有的独立完整配置，含可用出站及唯一的直连出口；使用 FakeIP 时还需有可用的本地 DNS 配置 |

这些流程修改已有配置，不会生成可导入所有客户端的通用配置包。不要选择订阅缓存或客户端临时生成的运行配置。

1. 选择对应类型，再点“选择配置文件”，查看改动摘要。
2. 确认后点“备份并保存”。配置原文和密码不会显示。
3. 回到代理客户端重新应用配置，再点“检测校园连接”。保存文件不会自动重载客户端。

Clash Verge Rev 的“复制校园扩展脚本”供熟悉脚本的用户合并使用，不能直接覆盖已有自定义脚本。订阅的后续扩展可能覆盖前面的修改，最终效果须重新检测。

已开启 DNS 覆写时，客户端还会写回覆写中的同名设置。需要追加校园 DNS 设置时，在原覆写中保留原值后追加，不更改原有过滤模式；不能仅靠扩展脚本保证生效。

Mihomo YAML 保存时会统一排版并移除注释，其他配置值保留，原文件可撤销恢复。

[sing-box for Desktop](https://sing-box.sagernet.org/clients/desktop/) 1.14.3 提供 Windows 程序 SFW，可从配置卡片的“＋ → 从文件导入”选择完整 JSON，再点“创建”。导入会复制内容；之后只修改原文件，不会同步更新已导入的配置。这不是规则片段或补丁的通用导入入口，深大随连不会代为导入或替换订阅。

文件流程只调整校园登录地址，保留其他规则及其顺序：让 `net.szu.edu.cn` 和 `172.30.255.42` 走直连；使用 FakeIP 时补充真实地址解析；支持时为宿舍地址补充 TUN 例外。不支持的配置停止保存，不关闭严格路由保护。

### macOS 文件保护与兼容范围

“高级：脚本与完整配置”允许选择本人维护的文件，先预览固定改动摘要，再备份保存。应用不展示、复制或导出文件中的节点、订阅和原文，也不执行选中的脚本。只接受空白、默认 `main` 函数或本应用生成的 Clash Verge Rev 脚本；已有自定义代码不覆盖。复制的固定脚本需由熟悉脚本的用户手动合并，不能当作通用 JSON 导入。

Mihomo 支持有界的 UTF-8 JSON 和保守 YAML 子集：缩进映射、序列（含映射）、简单行内标量数组，以及 JSON 语法的行内值。锚点、别名、标签、多文档、块文本和复杂行内 YAML 不支持，停止预览；可在客户端图形界面添加规则。保存后的内容为 JSON（YAML 1.2 的合法子集），注释与排版不保留，原字节可撤销恢复。未知值、大整数和字符串类型保留，不猜测歧义标量。

sing-box 支持独立 JSON 配置，要求唯一真实直连出站。使用 FakeIP 时还须存在唯一可用的本地 DNS tag；不制造解析器，不修改默认 DNS、其他规则、严格路由或 TUN 安全开关。Mihomo 的 FakeIP 黑名单和规则模式分别处理，白名单模式目前拒绝自动修改。

文件限 1 MB、UTF-8、本机当前用户拥有且可写的普通文件；不接受符号链接、硬链接或网络卷。保存前协调文件访问、复查身份与原文，加密保存原字节后在同目录原子替换。备份采用 AES-GCM，密钥由本机钥匙串保护；只保留一份待撤销备份。撤销时再次检查当前文件，后来被改过则保留现状。只有再次确认“保留现配置并移除备份”后才丢弃自己的撤销备份，不操作第三方备份。清理未完成时保留重试入口；处理完备份后才能选择其他配置。

**保存不等于联网恢复。**须在代理客户端重新应用，再回深大随连检测；应用不会重载客户端或修改系统代理、DNS、TUN、路由。校园连接检测与校园身份核验是独立结果。只读与离线预览不能选择、保存、撤销配置或访问正式备份密钥。卸载不自动回改第三方文件；选择清除本机数据会同时移除本应用的撤销备份与密钥，需要恢复时先撤销。

Windows 的文件保护方式不适用于 macOS。

</details>

## 常用网址检测

“使用系统设置／绕过系统代理”只控制深大随连检测常用网址的方式，不改变校园认证或代理客户端规则，也不会关闭、绕过 TUN。无需为校园登录切换这一选项。

## 恢复原配置

经深大随连保存的文件，可点“撤销上次更改”恢复。原文件会在保存前加密备份，仅保存在本机，由 Windows 当前用户的数据保护或 macOS 钥匙串密钥保护；只保留一份待撤销备份。

文件后来被改过时，应用会停止撤销，避免覆盖新内容。恢复后仍需在代理客户端重新应用配置。在客户端手动添加的规则及其他设置，须在客户端自行还原。

确认不再需要撤销时，可点“保留现配置并移除备份”，再处理其他配置文件。此操作不改当前代理配置；移除后无法一键恢复。

卸载深大随连不会自动改动外部配置。需要恢复原配置时，请先撤销，再卸载。
