# 安装、升级与卸载

从[项目下载页](https://github.com/zhihebai/SZUConnect/releases)选择平台安装包。源码压缩包不能直接运行。

## macOS

适用于 macOS 14+，支持 Apple 芯片与 Intel。

1. 打开 DMG，将“深大随连”拖入“应用程序”。
2. 推出 DMG，从“应用程序”打开。
3. 按需要处理定位和钥匙串授权。

下载包中的应用已签名并通过 Apple 公证。定位权限用于读取 Wi-Fi 信息；未授权时仍可检测联网，自动找网可能受限。

## Windows

适用于 Windows 11 x64。下载并运行 EXE，应用会安装到当前用户的程序目录，并创建开始菜单入口。无需安装额外运行库。

也可完整解压 ZIP，运行其中的 `SZUConnect.exe`；安装后的程序与“说明与许可”保存在一起。

Windows 包未代码签名。遇到系统提示时确认下载来自本项目，并遵守设备的安全策略。

关闭窗口后应用仍在托盘运行；从托盘菜单选择“退出”才会完全关闭。

## 升级

- Windows：下载并运行新 EXE，应用会退出旧实例、完成更新并重新打开，无需手动覆盖程序目录。
- macOS：先退出旧应用，再将新应用替换到“应用程序”并重新打开。

已保存的账号、设置和网络记忆会保留，无需删除账号或应用数据。

## 卸载

先关闭登录时启动，再退出应用。macOS 删除“应用程序”中的应用；Windows 删除 `%LOCALAPPDATA%\Programs\SZUConnect` 和开始菜单中的“深大随连”快捷方式。

删除程序不会自动清除账号、设置和记录。需要一并清理时，先在应用内删除账号、忘记网络，再按[隐私说明](PRIVACY.md)删除应用数据。旧下载和其他目录中的文件须自行确认后清理。
