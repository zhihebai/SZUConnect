# 安装、升级与卸载

到[下载页](https://github.com/zhihebai/SZUConnect/releases)选择对应系统的应用安装包；源码压缩包不能直接运行。

## macOS

适用于 macOS 14+，支持 Apple 芯片和 Intel。

1. 打开 DMG，把“深大随连”拖进“应用程序”。
2. 推出 DMG，从“应用程序”里打开。
3. 按页面提示处理定位和钥匙串授权。

macOS 版已签名并通过 Apple 公证。定位权限用来读取 Wi-Fi 名称；没有授权时，联网检测仍可正常使用，只是自动找网可能受限。

## Windows

适用于 Windows 11 x64。下载并运行 EXE，应用会装到当前用户的程序目录，并创建开始菜单入口，不需要另外安装运行库。

Windows 版尚未签名，首次打开可能出现系统安全提示。请从本项目下载。

关窗后，应用仍在托盘运行；从托盘菜单选“退出”，才会完全关闭。

## 升级

- Windows：下载并运行新 EXE，程序会自动更新并重新打开，无需查找旧程序目录。旧版仍在运行时，会先尝试正常退出旧版。
- macOS：先从菜单栏退出旧版，再打开新 DMG，把应用拖进“应用程序”。在提示中选“替换”，然后重新打开应用。

升级保留已保存的账号、设置和网络记忆，无需提前删除数据。

## 卸载

### Windows

在系统“设置 → 应用 → 已安装的应用”中找到“深大随连”，选择“卸载”；也可在应用内选择“设置 → 关于 → 卸载应用”。两处打开同一确认窗口。

确认后，卸载程序会退出应用，移除程序、开机启动和本应用快捷方式。默认保留账号和本机数据；需要清理时，勾选“同时删除已保存账号、设置、网络记忆和记录”。

### macOS

在应用内打开“设置 → 关于 → 卸载应用”。默认保留账号和本机数据；需要清理时，勾选“同时删除已保存账号、设置、网络记忆和记录”。确认卸载前，取消、关闭确认窗口或按 Escape 都不会改动应用和数据。

确认后，应用会注销“登录时打开”、停止后台任务，把自身移到废纸篓后退出。

勾选清理会同时删除本应用的钥匙串账号、设置、网络记忆、常用网址和记录，包括 Dock 偏好。**代理配置的撤销备份和密钥也会删除；需要恢复外部配置时，请先撤销，再卸载。**

请从“应用程序”中的正式应用执行卸载。若从 DMG 或下载目录打开，请先从菜单栏退出，把应用拖进“应用程序”，再从那里打开卸载。

位置检查未通过时，不会卸载或清理数据。权限不足或清理失败时，按提示处理后可重试。

也可先关闭“登录时打开”，从菜单栏退出，再把“应用程序”里的应用移到废纸篓。这样会保留账号和本机数据；下载包可另外删除。

## 开源许可

在“设置 → 关于 → 开源许可”中，可离线阅读、复制完整许可。
