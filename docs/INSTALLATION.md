# 安装、升级与卸载

从[下载页](https://github.com/zhihebai/SZUConnect/releases)选择对应系统的安装包。请下载应用包，源码压缩包不能直接运行。

## macOS

适用于 macOS 14+，支持 Apple 芯片与 Intel。

1. 打开 DMG，将“深大随连”拖入“应用程序”。
2. 推出 DMG，从“应用程序”打开。
3. 按页面提示处理定位和钥匙串授权。

macOS 版已签名并通过 Apple 公证。定位权限用于读取 Wi-Fi 名称；未授权时仍可检测联网，但自动找网可能受限。

## Windows

适用于 Windows 11 x64。下载并运行 EXE，应用会安装到当前用户的程序目录，并创建开始菜单入口。无需安装额外运行库。

也可解压 ZIP，运行其中的 `SZUConnect.exe`。两种下载方式的安装流程相同，程序与“说明与许可”保存在一起。

Windows 版尚未签名，首次打开可能出现系统提示。请确认文件来自本项目，并遵守设备的安全策略。

关闭窗口后应用仍在托盘运行；从托盘菜单选择“退出”才会完全关闭。

## 升级

升级前建议先从托盘或菜单栏退出应用。

- Windows：下载并运行新 EXE，应用会完成更新并重新打开，无需查找旧程序目录。若旧版仍在运行，更新程序会先尝试让它正常退出。
- macOS：打开新 DMG，将应用拖入“应用程序”，在提示中选择“替换”，再打开应用。

已保存的账号、设置和网络记忆会保留，无需删除账号或应用数据。

## 卸载

先在设置中关闭“开机启动”或“登录时打开”，再退出应用。

- macOS：删除“应用程序”中的“深大随连”。
- Windows：删除 `%LOCALAPPDATA%\Programs\SZUConnect` 和开始菜单中的“深大随连”快捷方式。

需要同时清除账号和使用记录时，请先在应用内删除账号、忘记网络，再按[数据清理](PRIVACY.md#删除数据)删除本机数据。删除程序本身不会清除这些内容，旧下载包可另行删除。
