# 安装、升级与卸载

到[下载页](https://github.com/zhihebai/SZUConnect/releases)选对应系统的安装包。请下载应用包，源码压缩包不能直接运行。

## macOS

适用于 macOS 14+，支持 Apple 芯片和 Intel。

1. 打开 DMG，把“深大随连”拖进“应用程序”。
2. 推出 DMG，从“应用程序”里打开。
3. 按页面提示处理定位和钥匙串授权。

macOS 版已签名并通过 Apple 公证。定位权限用来读取 Wi-Fi 名称；没有授权时，联网检测仍可正常使用，只是自动找网可能受限。

## Windows

适用于 Windows 11 x64。下载并运行 EXE，应用会装到当前用户的程序目录，并创建开始菜单入口，不需要另外安装运行库。

也可以解压 ZIP，运行里面的 `SZUConnect.exe`。两种下载方式的安装流程一样，程序和“说明与许可”放在一起。

Windows 版还没有签名，首次打开时可能出现系统提示。请确认文件来自本项目，并遵守设备的安全策略。

关掉窗口后，应用仍在托盘运行；从托盘菜单选“退出”，才会完全关闭。

## 升级

升级前，建议先从托盘或菜单栏退出应用。

- Windows：下载并运行新的 EXE，应用会自己完成更新并重新打开，不用找旧程序目录。如果旧版还在运行，更新程序会先试着让它正常退出。
- macOS：打开新的 DMG，把应用拖进“应用程序”，在提示里选“替换”，再打开应用。

已经保存的账号、设置和网络记忆都会保留，不用删账号或应用数据。

## 卸载

先在设置里关掉“开机启动”或“登录时打开”，再退出应用。

- macOS：删除“应用程序”里的“深大随连”。
- Windows：删除 `%LOCALAPPDATA%\Programs\SZUConnect`，以及开始菜单里的“深大随连”快捷方式。

想同时清掉账号和使用记录，先在应用里删除账号、忘记网络，再按[数据清理](PRIVACY.md#删除数据)删除本机数据。只删程序不会清掉这些内容；旧的下载包可以另外删。
