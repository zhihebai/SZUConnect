# Windows 与 Mac 的界面一致性

Windows 按 macOS 的信息层级和操作顺序布局，共用设计参数；界面使用 Win32、Direct2D、原生文本框和 UI Automation。

默认客户端为 500 × 700 DIP，最小客户端宽度为 500 DIP；外框按当前 DPI 换算，尺寸受显示器工作区限制。页面与弹层使用卡片、分组和逐级展开的结构，不额外缩小文字。

## 顶栏与窗口

工具栏与窗口按钮共用一行，通常高 56 DIP。顶栏按实际文字宽度选择布局：

| 可用空间 | 品牌与导航 |
| --- | --- |
| 较少 | “深大随连”、文字导航 |
| 足够 | “深大随连”、带图标的导航 |
| 较宽 | “深大随连”、带图标的导航 |

帮助紧随导航，点击区域为 44 DIP，与右侧窗口按钮至少相隔 6 DIP。品牌始终显示四字名称，只读标识放在名称下方。各项垂直居中，底线贯通全宽；500 DIP 默认窗口保持一行，更窄的隔离测试或更大文字下可使用第二行，不压缩字号。

窗口保留系统菜单、边角缩放及原生 TitleBar 辅助功能入口。客户端按钮对应最小化、最大化／还原和关闭命令，不重复创建可聚焦入口。DWM 优先处理非客户区命中和悬停；按下后移出、Escape、失焦或捕获丢失均取消操作。

模态弹层从顶栏下方开始，导航与帮助暂时禁用，窗口按钮仍可用。[窗口框架说明](https://learn.microsoft.com/en-us/windows/win32/dwm/customframe)

## 布局规则

| 内容 | 规则 |
| --- | --- |
| 页面 | 单列居中；左右 24、上下 20、模块间 16 DIP。连接页最大宽 760，记录和设置页 880 DIP；可手动加宽 |
| 导航 | 连接、记录、设置及帮助；图标 18 DIP，标题 14 DIP。浅色底板、白色选中项 |
| 状态卡 | 56 DIP 语义图标、22 DIP 标题；主操作突出，说明入口随标题或操作组排布，不单独挤到下一行 |
| 检测页脚 | 接入方式、检测时间按语义分段排列；检测方式始终另起一行、靠左排列，默认宽 190 DIP，与元信息保留 8 DIP，拉宽窗口时不移到旁边 |
| 普通分组 | 内边距 16 DIP。连接页标题视觉行高 28 DIP，说明按钮命中区 44 DIP，不与下方控件重叠 |
| 账号 | 已保存且无待保存修改时默认收起；展开后宽窗同行、窄窗堆叠。输入框内提示，密码显示按钮位于末尾，区域用菜单选择；修改后显示保存／放弃 |
| 网站 | 默认收起，展开后开关与移除同行，添加输入与按钮同行；直接显示失败和不明状态 |
| 记录 | 摘要、模式、筛选、导出、列表依次排列；“只看失败”紧邻复选框，详情标题与关闭同行，标签列宽 72 DIP |
| 设置 | 外观、启动、网络记忆、Wi-Fi 恢复、帮助依次排列；外观选择器填满宽度。Wi-Fi 开关、目标和状态集中在内边距 16 DIP 的卡片中 |
| 网络信息 | 展开箭头、图标、标题和摘要同行；展开后直接显示连接列表、刷新和两列联网检测，客户端配置与检测入口独立呈现 |
| 帮助／关于 | 固定头部及右上角关闭，正文独立滚动；外边距 20、卡间 16、卡内 16 DIP，使用分级标题、13 DIP 说明文字和 14 DIP 辅助图标 |
| 控件 | 共享字体、颜色和圆角；分段控件视觉高 28 DIP，输入框 32 DIP，按钮及图标操作命中区至少 44 DIP |

各页面、引导及对话框共用标题、卡片、说明和关闭规则。设置中的网络名称与核验日期同列，管理入口紧邻记录；右侧开关的标签和说明左对齐，复选框说明保留缩进。

同名网络保留原名和独立记录，不追加编号。同名组只显示一次说明，可靠匹配唯一记录时才标记“当前连接”；网络备注和找网选择保持原样。

窄窗按标题、按钮组和完整信息段换行。正文按实际可用宽度自然排版，不为末行较短而缩窄整段。静态长说明在共享源中按句意分行；放大文字时允许增加高度，保留全文。测量与绘制共用同一 DirectWrite 布局。

记录列表保留两层内边距：活动行外卡 8 DIP、行内横 12／纵 8 DIP；样本行外卡及行内均为 8 DIP。段间使用分隔线。

帮助由首次步骤、FAQ 和分类链接三张卡片组成。首次步骤和九个 FAQ 默认收起，可分别展开；首次步骤在本次运行中保留展开状态，FAQ 关闭帮助后恢复收起。关于由品牌、开发者、致谢和存储四张卡片组成。辅助对话框均固定右上角关闭，正文独立滚动。

参考视图位于 `macos/SZUConnect/Sources/`：`ContentView.swift`、`DesignSystem.swift`、`ConnectionPage.swift`、`RecordsPage.swift` 和 `SettingsPage.swift`。布局使用逻辑点／DIP，字体和系统窗口边框遵循各平台规则。

## 信息说明

各说明入口使用独立的非模态气泡。“i”图标为 16 DIP，悬停只改变颜色，键盘焦点显示小圆环；点击范围保留 44 DIP。信息按钮紧邻标题，网络展开行的说明位于行尾。

气泡默认宽 320 DIP，按文字大小、来源控件矩形及所在显示器工作区调整。优先放在所属卡片外；空间不足时保持标题和相关说明可见，正文独立滚动，关闭按钮固定。支持屏幕边缘、任务栏和负坐标副屏，主窗口仍可操作，无全页遮罩。

Escape、右上角关闭、重复点击、页面滚动或切换、失活、最小化及托盘隐藏均关闭气泡。关闭后，后台刷新不会再次弹出。

## 网络与记录

主状态卡只显示一组 Apple／Microsoft 结果标签，页脚标明“当前上网方式”或“校园直连”。网络详情对照两种检测结果，另列校园登录服务核验状态。

网络核验与记忆集中在自动重连卡的网络确认区，清单、状态卡及引导只定位到该处。三种普通检测模式均可管理网络，操作旁显示核验进度、取消和结果。

未记住网络时提供“核验并记住校园网络”；已记住后提供“核验校园服务”和“忘记此网络”。已记住但尚未核验的状态显示监测提示，核验进度和失败原因就近呈现，不重复提示记住网络。

本次信任、网络记忆、校园核验及重连开关分别呈现，当前校园服务未确认时不显示绿色就绪。

“网络详情”显示连接与代理状态、两列联网检测结果和“校园直连设置”入口。连接摘要与校园服务直接按标签和值排列；客户端配置步骤、校园连接检测及规则集中在“校园直连设置”。关闭该窗口或离开页面时取消诊断。

联网对比按两列显示各自的检测时间和结果，保留检测范围、说明和检测按钮。切换范围不生成新报告，已有结果及时间保持不变；没有结果时显示等待检测。“校园直连设置”中的高级配置默认收起。无法识别物理连接时，就近显示原因、刷新和复制摘要；刷新只更新连接信息，不授予网络信任或触发登录。

常用网址的检测方式放在同一卡片内，与网址列表相邻。共用说明和当前选项说明分段显示；两种方式仅影响常用网址，不改变基础检测或校园核验。

关于页先收纳整组开源许可，展开后可分别阅读、复制项目、AutoSZUWeb、libcurl 和 yaml-cpp 许可。删除账号确认框的关闭和操作按钮通常固定可见；窗口过矮时操作随正文滚动，关闭按钮仍固定。

校园直连设置依次展示所用软件、操作步骤和连接检测。脚本及完整配置文件置于默认收起的高级选项，普通步骤不要求用户寻找配置文件。

结果标签先为检测状态留出宽度，长网站名称单行省略，完整名称可从详情或辅助功能名称读取。标签按文字高度排布，可点击区域至少为 44 DIP。

选中的记录只保存在界面内存中，以完整样本字段和重复序号区分，时间不截断。同一时间的多条记录各自可选，每次只选中一条并显示其详情，记录文件格式不变。

滚动内容只绘制视口和边缘余量内的部分，固定关闭按钮与相交背景完整绘制。历史记录和辅助功能节点保留，UI Automation 相邻节点导航复用列表索引。

## 首次引导

引导使用两端统一的十一阶段及共享文案：欢迎、账号、检测、登录、记忆、恢复、网站、网络、启动、Wi-Fi、完成。

引导固定在导航下方，页面仍可操作，定位按钮展开并滚动到对应区域。前进、返回和跳过只更新引导进度，不执行检测、认证、网络信任或设置修改；完成／跳过标记保持兼容。

## 验证与边界

原生离线检查使用隔离假服务，共 24 帧：

- 三页窄窗、设置下半部、三页宽窗及账号／网站区域。
- 深色连接／设置、150% 文字连接页及字形样本。
- 关于顶部、详情及 150% 文字；帮助顶部、FAQ 展开、底部及 150% 文字。
- 网络详情及 150% 文字、选中记录详情、普通及 150% 文字的长网站名称。

场景更新并完成绘制后取样，记录实际客户端尺寸、文字倍率及主题。检查覆盖：

- 每帧矩形、水平边界、交互目标重叠及窗口按钮对齐，底线横向九处像素。
- 固定关闭、首次步骤与 FAQ 独立展开、官方链接、记录内边距及单层网络详情。
- 480／500 DIP 隔离布局下的短尾行、标题附件和按钮组；480 DIP 仅用于边界回归，正常窗口最小客户端宽度为 500 DIP。

回执采用 `schemaVersion 2`，相同文字渲染参数保存一次，各帧按索引引用并核对实际配置。JSON 上限为 16 KiB，图像总预算为 48 MiB。

自检与正式数据、凭据、网络、WLAN、观察器及启动项隔离，用户数据格式和设置保持原样。全部帧及布局检查通过后，才判定成功。

高 DPI 检查按实际像素宽度及 BMP 头计算可用高度。预算不足时只缩短隔离窗口，不改变 DPI、字体、字形像素或截图比例。正常程序的窗口尺寸不受影响，各帧实际尺寸以回执为准。

帮助／关于没有单选控件，选中像素检查标为不适用；其余帧检查实际选中像素。关于页另核对项目及上游链接地址和换行区域。

记录回归使用 1,100 条假记录，检查双向遍历、属性、生命周期、文字布局次数及滚动像素。

150% 文字检查调整的是应用内文字比例。Windows 11 实机另测 100%／150%／200% 系统显示缩放、跨显示器和窗口缩放，以及 Tab／Shift+Tab、方向键、Enter／Space／Escape、输入焦点、密码显示、网络展开及 Narrator。账号与 TUN 联网检查见[实体测试](../WINDOWS-TESTING.md)。

界面调整须保持认证规则、数据格式和账号兼容，不修改系统代理、VPN、DNS 或路由。

## 文字与启动窗口

主字体优先选择覆盖中文的 Microsoft YaHei UI／Microsoft YaHei，缺失时使用系统回退。DirectWrite 使用不透明 BGRA 目标及 `DEFAULT` 渲染模式，按字体和字号选择显示方式。

Windows 已启用 ClearType、显示器为 RGB／BGR 像素排列且校准参数有效时，使用 ClearType；其他情况使用灰阶抗锯齿。沿用显示器的 gamma、对比度等参数，在显示器、DPI 或系统文字设置改变时刷新，不修改系统字体设置。

标题保留强调字重，正文和辅助说明按层级区分。基线取自实际匹配字体的升部、降部指标；标题目标行高为字号的 1.25 倍，正文为 1.45 倍，均保留完整字形所需高度。字号不变，不添加描边或额外加粗。

原生 EDIT 输入框使用同一主字体，按 Windows 的 ClearType 偏好选择平滑方式，保留输入、密码隐藏、键盘及读屏行为。

回执记录实际抗锯齿模式、渲染策略、主字体、中文覆盖、显示器参数和目标；配置未实际应用则检查失败。

字形样本包含“十、土、士、干、千、王、三、田、目、日、口、中”，覆盖 12／14／18 DIP 及强调字重，用于检查细笔画间隙。原生字体回归另核对中文、标点和拉丁降部的字形覆盖、实际行距、基线及墨迹边界，按 125%–200% 配置 DPI 与 100%／150% 文字绘制。截图检查后，仍需在实际显示器上核对文字效果。

默认及最小窗口尺寸来自共享源中的 Windows 参数，不改变 Mac 默认尺寸。新实例保持 500 DIP 的紧凑客户端宽度；手动调整和托盘唤起不强制恢复默认尺寸。

顶栏始终显示产品名称，导航图标按空间保留。回执记录 `navigationTier` 与 `brandingPixelSamples`，核对品牌文字实际像素、导航容纳和 44 DIP 点击区域。关于页仍保留应用图标，不影响顶栏品牌检查。

## 单选高亮

检测范围、运行模式、登录区域、记录切换、外观及弹层选项统一使用分段／单选组件。分段选中项为共享 `selectionFill` 蓝底、`onSelection` 白字；顶部导航使用浅底蓝字，大型选项卡使用浅底、蓝边和单选圆点。

禁用选项显示当前选择，保持不可操作。浅色和深色主题分别检查文字对比度，高对比度模式使用系统选中颜色。选中状态保留粗体、单选指示及 UI Automation `checked` 状态，键盘焦点单独显示。

记录样本保留成功／异常的语义底色，用蓝色边框表示选中，保持结果含义可辨。
