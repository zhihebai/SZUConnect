# 隐私与数据

账号、设置、网络记忆和记录保存在本机。应用没有广告，不收集使用统计；排查摘要和报告只由你主动复制或保存，不会自动上传或发送邮件。

## 本机存储

- 校园账号和密码：保存在 macOS 钥匙串或 Windows 凭据管理器中，不写入普通配置文件。
- 网络记忆、名称和连接记录：保存在本机，用于显示、自动找网和排查。

Windows 找网可调用所选 Wi-Fi 已保存的系统连接，由系统使用原有无线凭据。应用不读取无线密码，也不修改已有无线配置。

<details>
<summary>数据目录和网络记忆</summary>

| 数据 | macOS | Windows |
| --- | --- | --- |
| 网络记忆、名称和连接记录 | `~/Library/Application Support/SZUConnect` | `%LOCALAPPDATA%\SZUConnect` |

macOS 的普通设置另存在系统偏好设置里。

网络记忆保存的是处理后的网络特征。网络名称和 Wi-Fi 名称另外存在本机，用来显示和自动找网。名称相同而连接特征不同的网络，需要分别核验并记住。

</details>

## 网络请求

基础检测访问 Apple 和 Microsoft 的联网检测页面；完整检测还会访问已启用的常用网址。校园账号只用于适用的校园网登录服务。

教学／办公区认证使用 HTTPS。**宿舍区按校园协议使用 HTTP，没有 HTTPS 的传输保护。**

应用不直接修改系统 VPN、代理、DNS 或路由。

<details>
<summary>地址查询和备用解析会发送什么？</summary>

应用先使用当前网卡的 DNS。解析失败时，仅为校园登录域名和两个基础检测域名尝试阿里公共 DNS 的加密解析，不发送账号、密码或自定义网址。

地址候选只保存在内存中，按物理连接区分。校园 HTTPS 证书和服务仍须重新核验，应用不会修改系统 DNS。

</details>

## 校园直连配置

“校园直连设置”只读取本人选定的文件，预览改动后才保存。配置可能含代理密码或订阅地址，其原文不在界面展示，也不进入连接记录或诊断导出。

原文件会先加密备份到本机，可用“撤销上次更改”恢复。文件后来被修改时，应用会停止撤销，避免覆盖新内容。

**需要恢复原配置时，请先撤销，再卸载。**卸载不会自动修改外部配置文件。[操作说明](PROXY-DIRECT.md)

<details>
<summary>备份如何保护？</summary>

Windows 使用当前用户的数据保护；macOS 使用 AES-GCM，备份密钥保存在系统钥匙串中。撤销会恢复保存前的原始字节。

</details>

## 分享内容

排查摘要和报告不含账号、密码、登录令牌、Wi-Fi 名称、终端 IP、网卡名称、配置原文或常用网址，也不保存完整的登录请求。

截图可能包含这些信息，分享前请检查并隐藏。

<details>
<summary>报告包含哪些诊断和故障记录？</summary>

摘要和 JSON 报告包含当前连接方式、系统代理及 TUN 状态、重连暂停原因和冷却剩余时间。这些信息仅用固定状态表示，不含网卡名称、地址或配置原文；连接信息正在更新时显示为未知。

新检测记录会保留各项耗时及检测时的匿名连接状态。连接或核验失败时，另保存当轮的核验结果、重连暂停与冷却、连接识别概况，便于恢复联网后回看故障。旧记录不补写这些信息。

</details>

<details>
<summary>会收集系统崩溃日志吗？</summary>

Windows 导出报告时，会按需查找最近 7 天本次程序对应的系统崩溃记录，最多 5 条。仅附时间、版本、错误码和可用的程序内偏移；不读取内存转储，不保存原始系统日志，也不附其他应用的记录。系统未记录或无法读取时，在报告中注明。

macOS 不扫描系统崩溃日志，也不读取 `.ips` 原文或内存转储。报告注明“未收集”，不据此判断应用从未崩溃。

macOS 在选择保存位置后固定该份报告内容，在后台整理和保存；取消选择不会开始整理。

</details>

## 删除数据

继续使用应用时，可分别操作：

- 删除账号：在“设置 → 关于 → 账号存储与隐私”选择“删除已保存账号”，保留其他设置和记录。
- 忘记网络：在设置中忘记单个网络，或确认“忘记全部网络”。
- 删除常用网址：在连接页移除。

### Windows 卸载

从系统“设置 → 应用 → 已安装的应用 → 深大随连 → 卸载”，或应用内“设置 → 关于 → 卸载应用”打开确认窗口。

默认保留账号和本机数据；勾选“同时删除已保存账号、设置、网络记忆和记录”可一并清理，无需另行查找凭据或数据目录。

### macOS 卸载

在“设置 → 关于 → 卸载应用”中操作，默认保留账号和本机数据。勾选清理后，会删除本应用的钥匙串账号、系统偏好设置、网络记忆、名称、常用网址和记录，包括 Dock 偏好。

**代理配置的撤销备份和密钥也会删除，外部配置不会自动恢复。需要恢复时，请先撤销。**

卸载仅处理核实属于本应用的项目。应用移入废纸篓，下载、源码及其他备份不会被清理。确认前，取消、关闭确认窗口或按 Escape 不会改动数据；清理未完成时，按窗口提示处理后可重试。

手动把应用移入废纸篓会保留账号和本机数据。

安全问题请按[安全报告](../SECURITY.md)的说明处理。
