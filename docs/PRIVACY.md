# 隐私与数据

## 本机存储

| 数据 | macOS | Windows |
| --- | --- | --- |
| 校园账号和密码 | 系统钥匙串 | Windows 凭据管理器 |
| 网络记忆、名称和连接记录 | `~/Library/Application Support/SZUConnect` | `%LOCALAPPDATA%\SZUConnect` |

macOS 的普通设置另存于当前用户的系统偏好设置。密码不写入普通配置文件。系统凭据保护依赖本机账户安全，不能保证抵御已控制当前用户环境的恶意程序。

网络记忆使用派生的网络特征；显示名称和 SSID 单独保存，只供本机显示与选定 Wi-Fi 恢复，不作为网络身份或认证权限。

## 网络请求

基础检测访问 Apple 和 Microsoft 的联网端点，完整检测也访问你启用的网址。校园认证只向适用的校园服务发送请求，无独立遥测或广告服务。

教学／办公区使用 HTTPS；宿舍区按校园协议使用 HTTP，不具备 TLS 传输保护。应用不修改 VPN、代理、DNS 或路由。

## 分享与删除

诊断不包含账号、密码、Cookie、令牌、真实 SSID 或自选网址，也不保存完整认证请求。分享截图或导出文件前，请检查敏感内容。

优先在应用中删除账号、忘记网络或删除常用网址。系统凭据项为 `local.SZUConnect.credentials`：Mac 可在“钥匙串访问”搜索；Windows 可在“凭据管理器 → Windows 凭据 → 通用凭据”查找。系统删除后请重开应用。

卸载应用不会自动删除凭据和本机数据。安全问题请按[报告方式](../SECURITY.md)处理。
