# 隐私与数据

## 本机存储

| 数据 | macOS | Windows |
| --- | --- | --- |
| 校园账号和密码 | 系统钥匙串 | Windows 凭据管理器 |
| 网络记忆、名称和连接记录 | `~/Library/Application Support/SZUConnect` | `%LOCALAPPDATA%\SZUConnect` |

macOS 的普通设置另存在系统偏好设置里。密码只由系统凭据服务保存，不写入普通配置文件。

网络记忆保存的是处理后的网络特征。网络名称和 Wi-Fi 名称另外存在本机，用来显示和自动找网；同名网络仍然要重新核验校园服务。

## 网络请求

基础检测访问 Apple 和 Microsoft 的联网检测页面；完整检测还会访问已启用的常用网址。账号只用于适用的校园网登录服务。应用没有广告，也不收集使用统计。

教学／办公区认证使用 HTTPS；宿舍区按校园协议使用 HTTP，没有 HTTPS 的传输保护。应用不会修改 VPN、代理、DNS 或路由。

## 分享内容

排查报告不含账号、密码、登录令牌、Wi-Fi 名称或常用网址，也不保存完整的登录请求。截图可能包含这些信息，分享前请检查并隐藏。

## 删除数据

在“设置 → 关于 → 账号存储与隐私”删除已保存账号，在设置中选择“忘记此网络”删除网络记忆，在连接页移除常用网址。需要彻底清理时，退出应用并删除上表中的数据目录；macOS 的普通设置按下文单独清除。

账号也可以从系统里删除，名称是 `local.SZUConnect.credentials`：

- macOS：在“钥匙串访问”里搜索。
- Windows：在“凭据管理器 → Windows 凭据 → 通用凭据”里查找。

macOS 的普通设置可在退出应用后，用 `defaults delete local.SZUConnect.mac` 删除。从系统删除账号后，如需继续使用应用，请重新打开应用。

卸载应用不会自动删除账号和本机数据。安全问题请按[安全报告](../SECURITY.md)的说明处理。
