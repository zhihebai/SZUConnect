# 隐私与数据

## 本机存储

| 数据 | macOS | Windows |
| --- | --- | --- |
| 校园账号和密码 | 系统钥匙串 | Windows 凭据管理器 |
| 网络记忆、名称和连接记录 | `~/Library/Application Support/SZUConnect` | `%LOCALAPPDATA%\SZUConnect` |

macOS 的普通设置另存于系统偏好设置。密码不写入普通配置文件；请同时保护好电脑与系统账户。

网络记忆保存处理后的网络特征。网络名称与 Wi-Fi 名称另存于本机，供显示和自动找网使用；同名网络仍需重新核验校园服务。

## 网络请求

基础检测访问 Apple 和 Microsoft 的联网检测页面，完整检测还会访问已启用的常用网址。账号只用于适用的校园网登录服务。应用无广告，不收集使用统计。

教学／办公区认证使用 HTTPS；宿舍区按校园协议使用 HTTP，没有 HTTPS 的传输保护。应用不修改 VPN、代理、DNS 或路由。

## 分享内容

排查报告不包含账号、密码、登录令牌、Wi-Fi 名称或常用网址，也不保存完整登录请求。截图可能包含这些信息，分享前请检查并隐藏。

## 删除数据

优先在应用中删除账号、忘记网络或移除常用网址。需要彻底清理时，退出应用，再删除上表中的应用数据目录。

账号也可从系统中删除，名称为 `local.SZUConnect.credentials`：

- macOS：在“钥匙串访问”中搜索。
- Windows：在“凭据管理器 → Windows 凭据 → 通用凭据”中查找。

macOS 的普通设置还可通过 `defaults delete local.SZUConnect.mac` 删除。操作前请退出应用，避免重新写入设置。若只从系统删除账号而继续使用应用，请重新打开应用。

卸载应用不会自动删除账号和本机数据。安全问题请按[安全报告](../SECURITY.md)说明处理。
