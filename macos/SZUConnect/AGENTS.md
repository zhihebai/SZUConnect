# Apple 平台开发约定

本目录遵守根目录 `AGENTS.md`，并补充以下要求。

## 工程与数据

- 工程由 `Scripts/generate_project.py` 生成，共享资源由根目录 `tools/generate_shared.py` 生成。
- 应用标识（bundle identifier）、系统钥匙串标识和已有数据格式必须保持兼容。
- 离线测试使用假服务和隔离数据。只读实例不得改写正式配置、请求系统权限或启动 Wi-Fi 恢复。

## 启动与后台运行

- 初始化模型、钥匙串和网络监控前，先取得当前应用身份对应的单实例锁，保证同一身份只运行一个实例。
- 离线预览使用独立的单实例锁，与正式应用分开。
- 重复启动只唤出已有窗口，不得新增后台守护实例。

## 签名与界面

- 保留定位权限配置（Location entitlement）和用途说明。
- 应用签名、应用公证和外层 DMG 公证须分别验证。
- 界面改动需检查实际布局、键盘焦点和读屏名称。
